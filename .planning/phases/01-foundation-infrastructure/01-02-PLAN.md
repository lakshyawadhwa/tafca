    1. **`src/common/context/request-context.ts`**: Create an AsyncLocalStorage instance that holds `{ firmId: string; userId: string; requestId: string }`. Export the storage instance and a typed `RequestContext` interface. Export helper functions `getRequestContext()` that returns the current store (throws if missing), `getFirmId()` shorthand, `getUserId()` shorthand, `getRequestId()` shorthand.

    ```typescript
    import { AsyncLocalStorage } from 'async_hooks';

    export interface RequestContext {
      firmId: string;
      userId: string;
      requestId: string;
    }

    export const requestContextStorage = new AsyncLocalStorage<RequestContext>();

    export function getRequestContext(): RequestContext {
      const ctx = requestContextStorage.getStore();
      if (!ctx) throw new Error('RequestContext not initialized — is middleware registered?');
      return ctx;
    }

    export function getFirmId(): string { return getRequestContext().firmId; }
    export function getUserId(): string { return getRequestContext().userId; }
    export function getRequestId(): string { return getRequestContext().requestId; }
    ```

    2. **`src/common/context/request-context.middleware.ts`**: NestJS middleware that extracts firmId and userId from the JWT payload on the request object (will be populated by auth guard in Phase 2) and wraps the remaining middleware chain inside `requestContextStorage.run(context, next)`. For now, since auth is Phase 2, read firmId and userId from `req.user` if present (populated by future JWT guard). Generate a `requestId` using `crypto.randomUUID()`. If `req.user` is not present (unauthenticated routes), run with firmId and userId as empty strings.

    ```typescript
    import { Injectable, NestMiddleware } from '@nestjs/common';
    import { Request, Response, NextFunction } from 'express';
    import { randomUUID } from 'crypto';
    import { requestContextStorage } from './request-context';

    @Injectable()
    export class RequestContextMiddleware implements NestMiddleware {
      use(req: Request, _res: Response, next: NextFunction) {
        const user = (req as any).user;
        const context = {
          firmId: user?.firmId || '',
          userId: user?.userId || user?.sub || '',
          requestId: (req.headers['x-request-id'] as string) || randomUUID(),
        };
        requestContextStorage.run(context, next);
      }
    }
    ```

    3. **`src/prisma/prisma.extensions.ts`**: Export a function `createFirmScopedClient(basePrisma: PrismaClient)` that returns `basePrisma.$extends(...)`. The extension uses the `query` component to intercept all model operations:

    - **Models to SKIP firm scoping** (no firm_id): `StatutoryDeadline`, `StatutoryDeadlineOverride`, `Session` (scoped by userId, not firmId). Define a `GLOBAL_MODELS` set.
    - **For all other models:**
      - On `findMany`, `findFirst`, `findFirstOrThrow`, `findUnique`, `findUniqueOrThrow`, `count`, `aggregate`, `groupBy`: Inject `where.firmId = getFirmId()` and `where.deletedAt = null` (soft delete filter). If getFirmId() returns empty string (unauthenticated), skip firm injection (allows system-level queries).
      - On `create`, `createMany`: Inject `data.firmId = getFirmId()` into the data payload.
      - On `update`, `updateMany`: Inject `where.firmId = getFirmId()` into the where clause.
      - On `delete`, `deleteMany`: Inject `where.firmId = getFirmId()`.
      - On `upsert`: Inject `where.firmId` and `create.firmId`.

    Use the `$allOperations` approach for simplicity rather than per-operation hooks. The extension accesses `getFirmId()` from the request-context module (which reads AsyncLocalStorage).

    Important: The soft-delete filter (`deletedAt = null`) should be applied on reads. For models without `deletedAt` (Session, UserRoleHistory, TaskDependency, TaskActivityLog, ComplianceCalendarEntry, CredentialAccessLog, etc.), skip the soft-delete filter. Define a `MODELS_WITHOUT_SOFT_DELETE` set.

    4. **`src/prisma/prisma.service.ts`**: Create PrismaService extending PrismaClient, implementing `OnModuleInit` and `OnModuleDestroy`. Connect on init, disconnect on destroy. Expose a `withFirmScope()` method that returns the extended client from `createFirmScopedClient(this)`. Cache the extended instance per request or create once.

    ```typescript
    import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
    import { PrismaClient } from '@prisma/client';
    import { createFirmScopedClient } from './prisma.extensions';

    @Injectable()
    export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
      private _scopedClient: ReturnType<typeof createFirmScopedClient> | null = null;

      async onModuleInit() { await this.$connect(); }
      async onModuleDestroy() { await this.$disconnect(); }

      get scoped() {
        if (!this._scopedClient) {
          this._scopedClient = createFirmScopedClient(this);
        }
        return this._scopedClient;
      }

      // Unscoped client for system operations (seeding, migrations, auth)
      get unscoped(): PrismaClient { return this; }
    }
    ```
