**Dashboard Module (per PAGE-06 / CONTEXT.md):**

1. **`dto/dashboard-response.dto.ts`**: Define response DTOs:
   - `TaskSummaryDto`: `{ overdue: number, dueToday: number, dueThisWeek: number, inReview: number }`
   - `DashboardTaskDto`: `{ id, title, status, priority, dueDate, clientName?, assigneeName? }` -- compact task for list display
   - `DashboardNotificationDto`: `{ id, type, title, body, entityType, entityId, createdAt, readAt }` -- compact notification
   - `DashboardResponseDto`: `{ taskSummary: TaskSummaryDto, myTasks: DashboardTaskDto[], approvalQueue: DashboardTaskDto[], recentNotifications: DashboardNotificationDto[] }`

2. **`dashboard.service.ts`** -- Extends FirmScopedService. Single method:

   **`getDashboard(userId: string, userRole: string)`**:
   - Compute date boundaries: `today` (start of day, hours zeroed), `tomorrow` (today + 1 day), `weekFromNow` (today + 7 days).
   - IMPORTANT: For date comparisons with Prisma `@db.Date` fields, use date ranges to avoid timezone issues. "Due today" = `{ gte: today, lt: tomorrow }`. "Overdue" = `{ lt: today }`. "Due this week" = `{ gte: today, lte: weekFromNow }`.
   - Active statuses filter: `{ notIn: [TaskStatus.DONE, TaskStatus.CANCELLED] }`
   - Run all queries in `Promise.all()` for parallel execution:
     a. **overdue count**: `this.prisma.task.count({ where: { assigneeId: userId, status: activeStatuses, dueDate: { lt: today } } })`
     b. **dueToday count**: `this.prisma.task.count({ where: { assigneeId: userId, status: activeStatuses, dueDate: { gte: today, lt: tomorrow } } })`
     c. **dueThisWeek count**: `this.prisma.task.count({ where: { assigneeId: userId, status: activeStatuses, dueDate: { gte: today, lte: weekFromNow } } })`
     d. **inReview count**: For PARTNER/MANAGER only, count tasks WHERE `status = PARTNER_APPROVAL` AND `(reviewerId = userId)`. For other roles, return 0.
     e. **myTasks**: `this.prisma.task.findMany({ where: { assigneeId: userId, status: activeStatuses }, orderBy: [{ dueDate: 'asc' }], take: 10, select: { id, title, status, priority, dueDate, client: { select: { displayName } } } })`
     f. **approvalQueue**: For PARTNER/MANAGER: tasks WHERE `status = PARTNER_APPROVAL` AND `(reviewerId = userId)`, ordered by `dueDate ASC, priority DESC`, take 10. Include client displayName and assignee fullName. For other roles: empty array `[]`.
     g. **recentNotifications**: `this.prisma.notification.findMany({ where: { recipientId: userId }, orderBy: { createdAt: 'desc' }, take: 5 })`
   - Map results to DTOs and return `DashboardResponseDto`.

3. **`dashboard.controller.ts`** -- `@Controller('dashboard')`:
   - `GET /` -- extracts userId and role from request context, calls dashboardService.getDashboard(). No role restriction (all users see their own dashboard).

**Recently Deleted Module (per DEL-01, DEL-02, DEL-03 / CONTEXT.md):**

1. **`dto/recently-deleted-response.dto.ts`**: 
   - `RecentlyDeletedItemDto`: `{ entityType: string, entityId: string, name: string, deletedAt: Date, deletedByName: string, daysRemaining: number }`
   - `RecentlyDeletedResponseDto`: `{ data: RecentlyDeletedItemDto[] }` -- no pagination (per CONTEXT.md, unlikely > 50 records at MVP scale)

2. **`dto/list-recently-deleted-query.dto.ts`**: 
   - `ListRecentlyDeletedQueryDto` with `entityType` (optional, IsString) for filtering. Values: 'Client', 'Engagement', 'Task'.

3. **`dto/restore-params.dto.ts`**:
   - `RestoreParamsDto` for path params: `entityType` (IsString, IsIn(['Client', 'Engagement', 'Task'])), `entityId` (IsUUID).

4. **`recently-deleted.service.ts`** -- Extends FirmScopedService:

   **`listRecentlyDeleted(query?: ListRecentlyDeletedQueryDto)`** (per DEL-01, DEL-03):
   - CRITICAL: Use `this.unscopedPrisma` because the scoped client auto-filters `deletedAt IS NULL`, which would exclude all deleted records. Always include explicit `firmId: this.getFirmId()` in WHERE.
   - Compute 30-day boundary: `const thirtyDaysAgo = new Date(); thirtyDaysAgo.setDate(thirtyDaysAgo.getDate() - 30);`
   - Build deletedWhere: `{ firmId: this.getFirmId(), deletedAt: { not: null, gte: thirtyDaysAgo } }`
   - If `query.entityType` is set, only query that entity table. Otherwise query all 3.
   - Run parallel queries via `Promise.all()`:
     - `this.unscopedPrisma.client.findMany({ where: deletedWhere, select: { id, displayName, deletedAt, deletedBy } })`
     - `this.unscopedPrisma.engagement.findMany({ where: deletedWhere, select: { id, name, deletedAt, deletedBy } })`
     - `this.unscopedPrisma.task.findMany({ where: deletedWhere, select: { id, title, deletedAt, deletedBy } })`
   - Batch-fetch user names for all unique `deletedBy` UUIDs (single `unscopedPrisma.user.findMany` with `id: { in: uniqueIds }`). Build userMap for display names.
   - Merge results into a single array, tag each with `entityType` ('Client', 'Engagement', 'Task'), map `displayName`/`name`/`title` to `name`, resolve `deletedBy` to `deletedByName` via userMap.
   - Compute `daysRemaining` for each: `30 - Math.floor((Date.now() - deletedAt.getTime()) / (1000 * 60 * 60 * 24))`. Clamp to minimum 0.
   - Sort by `deletedAt DESC` (newest deletions first).
   - Return `{ data: RecentlyDeletedItemDto[] }`.

   **`restore(entityType: string, entityId: string)`** (per DEL-02):
   - PARTNER only (enforced at controller level).
   - Use `this.unscopedPrisma` with explicit `firmId`.
   - Find the record in the correct table based on entityType:
     - 'Client': `unscopedPrisma.client.findFirst({ where: { id: entityId, firmId: this.getFirmId(), deletedAt: { not: null } } })`
     - 'Engagement': same pattern on engagement table
     - 'Task': same pattern on task table
   - Validate: record exists, `deletedAt` is within 30 days. If not found, throw NotFoundException. If > 30 days, throw BadRequestException("Record has expired and cannot be restored").
   - **Unique constraint check for clients**: Before restoring a client, check if another active client exists with the same `displayName` in the firm: `unscopedPrisma.client.findFirst({ where: { firmId, displayName: record.displayName, deletedAt: null, id: { not: entityId } } })`. If found, throw ConflictException("Cannot restore: a client named '{name}' already exists").
   - Update the record: set `deletedAt = null`, `deletedBy = null`, `updatedBy = this.getUserId()`.
   - Return `{ message: 'Restored successfully' }`.

5. **`recently-deleted.controller.ts`** -- `@Controller('recently-deleted')`:
   - `GET /` -- `@Roles(UserRole.PARTNER, UserRole.ADMIN)`. Query: ListRecentlyDeletedQueryDto. Returns recently deleted list.
   - `POST /:entityType/:entityId/restore` -- `@Roles(UserRole.PARTNER)`. PARTNER only (stricter than list). Params: RestoreParamsDto. Returns success message.

6. **`recently-deleted.module.ts`**: NestJS module importing PrismaModule.
