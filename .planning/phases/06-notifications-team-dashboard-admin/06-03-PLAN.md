- GET /api/notifications?page=1&limit=20&unreadOnly=true -> { data: NotificationDto[], meta: { total, page, limit, totalPages, unreadCount } }

- GET /api/team/workload -> { data: WorkloadUserDto[], firmAverage: number }

- GET /api/team/leave?page=1&limit=20&status=&userId= -> paginated leave list
- PATCH /api/team/leave/:id/approve -> LeaveDto

- PATCH /api/team/leave/:id/cancel -> LeaveDto

Settings API:
- GET /api/firms/settings -> FirmSettingsResponseDto
- PATCH /api/firms/settings { fields } -> FirmSettingsResponseDto

Recently Deleted API:
- GET /api/recently-deleted?entityType= -> { data: RecentlyDeletedItemDto[] }
