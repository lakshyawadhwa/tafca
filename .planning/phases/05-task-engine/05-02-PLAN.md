    - `label` (IsString, IsNotEmpty, MaxLength(300))

    **update-checklist-item.dto.ts:**
    - `label` (IsOptional, IsString, MaxLength(300))

    - `isRequired` (IsOptional, IsBoolean)

    **TaskChecklistService** extending FirmScopedService (per CONTEXT.md locked decision). Inject TaskActivityService.

    **addItem(taskId: string, dto: CreateChecklistItemDto)** (per TASK-08):
    - Verify task exists: `this.prisma.task.findUnique({ where: { id: taskId } })`. Throw NotFoundException if not found.
    - Count existing items: `this.prisma.taskChecklist.count({ where: { taskId } })`. If >= `LIMITS.MAX_CHECKLIST_ITEMS_PER_TASK` (30), throw `BadRequestException('Maximum of 30 checklist items per task')`.
    - Get next displayOrder: max existing + 1.
    - Create item with `taskId`, `firmId: this.getFirmId()`, `label: dto.label`, `isRequired: dto.isRequired ?? true`, `displayOrder`, `createdBy/updatedBy: this.getUserId()`.
    - Return created item.

    **updateItem(taskId: string, itemId: string, dto: UpdateChecklistItemDto):**
    - Find item by id and taskId. NotFoundException if not found.
    - If `dto.isCompleted` is provided and differs from current:
      - If toggling to completed: set `completedAt = new Date()`, `completedBy = this.getUserId()`. Fire-and-forget: `activityService.log(taskId, TaskAction.CHECKLIST_ITEM_COMPLETED, null, item.label)`.
      - If toggling to uncompleted: set `completedAt = null`, `completedBy = null`. Fire-and-forget: `activityService.log(taskId, TaskAction.CHECKLIST_ITEM_UNCOMPLETED, null, item.label)`.
    - Update all provided fields.
    - Return updated item.

    **deleteItem(taskId: string, itemId: string):**
    - Soft-delete the item (set deletedAt, deletedBy). NotFoundException if not found.

    **listItems(taskId: string):**
    - Return all items for taskId, ordered by `displayOrder` ascending.

    **reorderItems(taskId: string, itemIds: string[]):**
    - Update displayOrder for each item based on array position. Use a transaction: `this.prisma.$transaction(itemIds.map((id, i) => this.prisma.taskChecklist.update({ where: { id }, data: { displayOrder: i } })))`.

    ---

    **TaskDependencyService** extending FirmScopedService. Inject TaskActivityService, TaskNotificationHelper.

    **addDependency(taskId: string, dto: CreateDependencyDto)** (per TASK-09, CONTEXT.md Dependency Management decision):
    1. Validate `taskId !== dto.dependsOnTaskId` (self-dependency). Throw `BadRequestException('A task cannot depend on itself')`.
    2. Verify both tasks exist in same firm via `this.prisma.task.findUnique()` for both. NotFoundException if either not found.
    3. Check for existing duplicate: `this.prisma.taskDependency.findFirst({ where: { taskId, dependsOnTaskId: dto.dependsOnTaskId } })`. If exists, throw `ConflictException('Dependency already exists')`.
    4. Run cycle detection via `hasCycle(taskId, dto.dependsOnTaskId)`. If cycle detected, throw `BadRequestException('Cannot add dependency: circular dependency detected')`.
    5. Create `TaskDependency` record with `firmId: this.getFirmId()`.
    6. Fire-and-forget: `activityService.log(taskId, TaskAction.DEPENDENCY_ADDED, null, predecessorTitle)`.
    7. Return created dependency with predecessor task info.

    **private async hasCycle(taskId: string, dependsOnTaskId: string): Promise<boolean>** (per RESEARCH.md Pattern 2):
    - BFS from `dependsOnTaskId`. Walk all its `dependsOn` edges. If we reach `taskId`, cycle detected.
    - Use `this.prisma.taskDependency.findMany()` (firm-scoped, per RESEARCH Pitfall 4) for traversal.
    - Small graph sizes (tasks within engagement) make this performant.

    **removeDependency(taskId: string, dependsOnTaskId: string):**
    - Find and delete the dependency record. NotFoundException if not found.
    - Fire-and-forget: `activityService.log(taskId, TaskAction.DEPENDENCY_REMOVED, predecessorTitle, null)`.

    **getDependencies(taskId: string):**
    - Return two lists:
      - `blockedBy`: `this.prisma.taskDependency.findMany({ where: { taskId }, include: { dependsOnTask: { select: { id, title, status } } } })`
      - `blocking`: `this.prisma.taskDependency.findMany({ where: { dependsOnTaskId: taskId }, include: { task: { select: { id, title, status } } } })`

    **TaskCommentService** extending FirmScopedService. Inject TaskActivityService, TaskNotificationHelper.

    **addComment(taskId: string, dto: CreateCommentDto)** (per TASK-11, CONTEXT.md Comments decision):
    - Verify task exists. NotFoundException if not.
    - If `dto.parentCommentId` is provided (threading, per RESEARCH Pitfall 7):
      - Fetch parent comment. NotFoundException if not found.
      - Verify `parentComment.parentCommentId === null` (only one level of replies). If parent itself has a parent, throw `BadRequestException('Reply depth limited to 1 level — cannot reply to a reply')`.
      - Verify parent comment belongs to same task.
    - Create comment with `taskId`, `firmId: this.getFirmId()`, `authorId: this.getUserId()`, `body`, `mentions: dto.mentions || []`, `parentCommentId`, `createdBy/updatedBy: this.getUserId()`.
    - Fire-and-forget: `activityService.log(taskId, TaskAction.COMMENT_ADDED, null, body.substring(0, 100))`.
    - Fire-and-forget (if mentions present): `notificationHelper.onCommentMention(taskId, dto.mentions)`.
    - Return created comment with author info.

    **updateComment(taskId: string, commentId: string, dto: UpdateCommentDto):**
    - Find comment by id and taskId. NotFoundException if not found.
    - Verify `comment.authorId === this.getUserId()` (only own comments editable). Throw `ForbiddenException('You can only edit your own comments')` if not.
    - Update body and/or mentions.
    - Return updated comment.

    **deleteComment(taskId: string, commentId: string):**
    - Find comment. NotFoundException if not found.
    - Verify ownership (same as update).
    - Soft-delete (set deletedAt, deletedBy).

    **listComments(taskId: string, page: number, limit: number):**
    - Fetch top-level comments (parentCommentId IS NULL), newest first, paginated.
    - For each top-level comment, include `replies` sorted oldest-first: `replies: { where: { deletedAt: null }, orderBy: { createdAt: 'asc' }, include: { ... } }`.
    - Include author info: `select: { id: true, fullName: true }` from user relation (use `unscopedPrisma.user.findUnique` lookup or include via Prisma relation if available).
    - Note: TaskComment doesn't have a direct user relation in the schema, so author info needs to be fetched separately. Batch-fetch unique authorIds from comments, query users, and map names onto comment responses.
    - Return `{ data: CommentDto[], meta: { total, page, limit, totalPages } }`.
