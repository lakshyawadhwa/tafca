    **Create TaskService extending FirmScopedService (per CONTEXT.md locked decisions).** Inject TaskActivityService and TaskNotificationHelper. Use `private readonly logger = new Logger(TaskService.name)` for logging.

    **createTask(dto: CreateTaskDto)** (per TASK-01):
    - If `dto.parentTaskId` is provided, enforce subtask depth limit (per TASK-06): fetch parent task, verify `parent.parentTaskId === null`. If parent has a parent, throw `BadRequestException('Subtask depth limited to 1 level — cannot create a subtask of a subtask')`.
    - If `dto.engagementId` is provided, verify engagement exists in same firm. Auto-set `clientId` from engagement if not provided.
    - If `dto.clientId` is provided (without engagement), verify client exists in same firm.
    - Compute internal due date (per TASK-05, CONTEXT.md Internal Due Date decision): if `dto.dueDate` is set and `dto.internalDueDate` is NOT provided, fetch `firm.settings` JSONB from `this.unscopedPrisma.firm.findUnique({ where: { id: this.getFirmId() } })`, extract `default_internal_deadline_buffer_days` (default 3), compute `internalDueDate = dueDate - bufferDays`. If `dto.internalDueDate` IS explicitly provided, use it. Validate `internalDueDate <= dueDate`.
    - Build Prisma create data with `firmId: this.getFirmId()`, `createdBy: this.getUserId()`, `updatedBy: this.getUserId()`, and all DTO fields.
    - If `dto.initialChecklistItems` is provided (and non-empty), use `this.prisma.task.create()` with nested `checklists: { create: items.map((item, i) => ({ firmId, label: item.label, isRequired: item.isRequired, displayOrder: i, createdBy: userId, updatedBy: userId })) }`.
    - Fire-and-forget: `this.activityService.log(task.id, TaskAction.CREATED, null, { title, status, priority }).catch(() => {})`.
    - If `dto.assigneeId`, fire-and-forget: `this.notificationHelper.onAssigneeChange(task, null, dto.assigneeId).catch(() => {})`.
    - Return task via `toTaskResponse()` helper.

    **getTask(id: string)** — findUnique with select including client (id, displayName), engagement (id, name), assignee (id, fullName), reviewer (id, fullName), parentTask (id, title), `_count: { subTasks: true }`, and checklist aggregation for progress. Compute `isBlocked` by checking `dependsOn` relations where `dependsOnTask.status NOT IN (DONE, CANCELLED)`. Throw NotFoundException if not found.

    **listTasks(query: ListTasksQueryDto)** (per TASK-07):
    - Build Prisma `where` clause from all filter params. Pattern: follow `ClientService.listClients()` exactly.
    - `search` -> `title: { contains: search, mode: 'insensitive' }`
    - `status` (comma-separated) -> `status: { in: statuses }`
    - `priority` (comma-separated) -> `priority: { in: priorities }`
    - `assigneeId`, `clientId`, `engagementId` -> direct equality
    - `dueDateFrom/dueDateTo` -> `dueDate: { gte/lte }`
    - `overdue` -> `dueDate: { lt: today }, status: { notIn: [DONE, CANCELLED] }`
    - Default: only top-level tasks (`parentTaskId: null`) unless `parentTaskId` filter is explicitly provided
    - Include computed fields in response: `checklistProgress` via `_count` aggregation on task checklists (count where isCompleted=true / total count). For `isBlocked`, include `dependsOn: { select: { dependsOnTask: { select: { status: true } } } }` and compute client-side per the RESEARCH.md anti-N+1 guidance.
    - Use `Promise.all([findMany, count])` pattern for pagination.
    - Include related data: `client: { select: { id, displayName } }`, `engagement: { select: { id, name } }`, `assignee: { select: { id, fullName } }`.

    **updateTask(id: string, dto: UpdateTaskDto):**
    - Fetch existing task first for comparison (needed for activity log old values).
    - If `dto.dueDate === null`, also set `internalDueDate = null` (per CONTEXT.md / RESEARCH Pitfall 6).
    - If `dto.dueDate` is set and `dto.internalDueDate` is NOT provided in this update, recompute internal due date from firm buffer.
    - If `dto.internalDueDate` is explicitly provided, validate `<= dueDate`.
    - Track field changes for activity log. For each changed field, fire-and-forget `activityService.log()` with appropriate `TaskAction`:
      - assigneeId -> `ASSIGNEE_CHANGED` + notification
      - reviewerId -> `REVIEWER_CHANGED`
      - dueDate -> `DUE_DATE_CHANGED`
      - priority -> `PRIORITY_CHANGED`
    - Return updated task via `toTaskResponse()`.

    **changeTaskStatus(id: string, dto: ChangeTaskStatusDto)** (per TASK-02, following EngagementService.changeEngagementStatus() pattern exactly):
    - Fetch task with `select: { id, status, assigneeId, reviewerId, engagementId, clientId }`.
    - Validate transition: `TASK_STATUS_TRANSITIONS[currentStatus].includes(targetStatus)`. If invalid, throw `BadRequestException({ message: 'Cannot transition from X to Y', allowed_transitions: TASK_STATUS_TRANSITIONS[currentStatus] })`.
    - DONE gate (per TASK-03): count `taskChecklist` where `taskId, isRequired: true, isCompleted: false`. If > 0, throw `ConflictException({ message: 'Cannot mark as done: N required checklist items are incomplete', incomplete_required_items: count })`.
    - Auto-set timestamps (per TASK-04): if DONE, set `completedAt = new Date()`. If CANCELLED, set `cancelledAt = new Date()`.
    - Update task with new status + timestamps.
    - Fire-and-forget: `activityService.log(id, TaskAction.STATUS_CHANGED, currentStatus, targetStatus)`.
    - Fire-and-forget: `notificationHelper.onStatusChange(task, currentStatus, targetStatus)`.
    - If targetStatus is DONE (per TASK-10 prerequisite): call `checkDependencyUnblocking(id)` fire-and-forget.

    **checkDependencyUnblocking(taskId: string)** (private method, per TASK-10):

    - For each dependent task, check if ALL its `dependsOn` tasks are now DONE or CANCELLED.
    - If all dependencies are resolved, emit `TASK_DEPENDENCY_UNBLOCKED` notification to the dependent task's assignee.

    **deleteTask(id: string):**
    - Soft-delete: set `deletedAt` and `deletedBy`. NotFoundException if not found.

    **toTaskResponse(raw)** — private helper that maps Prisma result to TaskResponseDto. Computes `checklistProgress` and `isBlocked` from included relations. Maps relation objects to `{ id, displayName/fullName/name }` shapes.
