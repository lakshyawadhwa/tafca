    **1. clickOutside.ts** — Svelte action for click-outside detection:
    - Export function `clickOutside(node: HTMLElement, callback: () => void)`
    - Add click listener to document, check if event.target is outside node
    - Return destroy() to clean up listener
    - Use Svelte action signature: returns `{ destroy(): void }`
    - Small delay (10ms) before attaching listener to avoid catching the click that opened the element

    **2. focusTrap.ts** — Svelte action for modal focus trapping:
    - Export function `focusTrap(node: HTMLElement)`
    - On mount: find all focusable elements inside node (input, button, a, select, textarea, [tabindex])
    - Listen for keydown Tab: if shift+tab on first element, wrap to last; if tab on last, wrap to first
    - Listen for keydown Escape: dispatch custom event or call optional callback
    - Auto-focus first focusable element on attach
    - Return destroy() to clean up listeners
    - ~25-30 lines, handles basic tab cycling per UI-SPEC

    **3. FormField.svelte** (COMP-03) — Input wrapper with label and error:
    - Props ($props()): label (string), error (string | null), helpText (string | null), required (boolean, default false), children (Snippet)

    - Render: label element (text-sm font-semibold text-gray-700, per UI-SPEC Label), required asterisk in text-red-500

    - Error: text-xs text-red-600, mt-1 (4px gap)
