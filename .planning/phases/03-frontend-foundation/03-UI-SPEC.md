## Spacing Scale

Declared values (multiples of 4, 8-point grid):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding-x |
| sm | 8px | Compact element spacing, input padding-y, table cell padding |
| md | 16px | Default element spacing, card padding, input padding-x |
| lg | 24px | Section padding, sidebar item padding-x, modal padding |
| xl | 32px | Layout gaps, sidebar padding-y, form group spacing |
| 2xl | 48px | Major section breaks, auth card vertical padding |
| 3xl | 64px | Page-level spacing, sidebar header height, topbar height |

Exceptions:
- Sidebar expanded width: 240px (CONTEXT.md decision, not on grid -- standard SaaS convention)
- Sidebar collapsed width: 64px (on grid)
- Mobile breakpoint: 768px (Tailwind `md:` default)
- Minimum touch target: 44px (accessibility, iOS HIG)

**Source:** Claude's Discretion -- CONTEXT.md delegated exact spacing scale.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 14px | 400 (regular) | 1.5 (21px) | `text-sm font-normal leading-relaxed` |
| Label | 14px | 600 (semibold) | 1.4 (19.6px) | `text-sm font-semibold leading-snug` |
| Heading | 20px | 600 (semibold) | 1.2 (24px) | `text-xl font-semibold leading-tight` |
| Display | 28px | 600 (semibold) | 1.2 (33.6px) | `text-2xl font-semibold leading-tight` |

**Rationale:** 14px body is standard for data-dense SaaS dashboards -- maximizes information density while remaining readable. Inter's x-height makes 14px feel roomy. Display (28px) used only for auth page headings and marketing-style hero text. Two weights only (400, 600) -- Inter's 600 provides sufficient contrast for headings and labels.

**Font loading:** `<link>` in `app.html` head:
```
Inter weights 400, 600 — subset: latin, latin-ext
```

**Fallback stack:** `'Inter', ui-sans-serif, system-ui, -apple-system, sans-serif`

**Source:** Claude's Discretion -- CONTEXT.md delegated exact sizes. Inter font from CONTEXT.md decisions.

## Layout Contract

### Auth Pages (Login, Register)

- Full viewport height, centered horizontally and vertically
- Background: subtle gradient from `gray-50` to `gray-100` (top to bottom)
- Card: `white` bg, `rounded-lg`, `shadow-lg`, max-width 420px, padding 32px (xl) horizontal, 48px (2xl) vertical
- Logo/app name at top of card: "CA Practice OS" in Display size (28px, bold)
- Subtitle below logo: Body size (14px, regular), `gray-500`
- Form inputs: full width, 40px height, 16px horizontal padding, 8px vertical padding
- Submit button: full width, 44px height, `blue-600` bg, white text, 600 weight, `rounded-md`
- Link to alternate page below form: "Don't have an account? Register" / "Already have an account? Sign in"
- Field error text: 12px, `red-600`, appears below input with 4px gap

### App Shell (Authenticated)

- Sidebar: fixed left, full viewport height, `white` bg, `gray-200` right border
  - Expanded: 240px wide
  - Collapsed: 64px wide (icons only, tooltip on hover)
  - Toggle: chevron button at bottom of sidebar (desktop), auto-collapses below 768px
  - Header: 64px tall, logo/app name (collapses to icon)
  - Nav items: 40px tall, 24px left padding, 8px gap between items
  - Active item: `blue-50` bg, `blue-600` text, left 3px border accent
  - Hover item: `gray-100` bg
  - Icon size: 20px (Lucide default), 12px gap to label text
- Topbar: full width minus sidebar, 64px tall, `white` bg, `gray-200` bottom border
  - Left: breadcrumbs (14px, `gray-500` separators, last item `gray-900` non-linked)
  - Right: notification bell icon (20px, `gray-500`, badge dot for unread) + user avatar (32px circle, initials fallback) + dropdown arrow
- Content area: below topbar, right of sidebar, `gray-50` bg, 24px padding (lg)
- User dropdown menu: `white` bg, `rounded-md`, `shadow-lg`, 8px padding-y
  - Items: Profile, Settings, divider, Sign out
  - Sign out text: `red-600`

### Responsive Behavior

| Viewport | Sidebar | Topbar | Content |
|----------|---------|--------|---------|
| >= 1024px (lg) | 240px expanded | visible | full with sidebar offset |
| 768-1023px (md) | 64px collapsed | visible | full with collapsed sidebar offset |
| < 768px (sm) | hidden (overlay on toggle) | visible, hamburger menu added | full width |

**Source:** CONTEXT.md decisions for layout dimensions and behavior. Claude's Discretion for responsive breakpoints and exact measurements.

## Interaction Contracts

### Toast Behavior

- Position: top-right, 24px from viewport edges
- Stack: newest on top, max 3 visible, older toasts slide up
- Auto-dismiss: success/info after 4 seconds, error after 8 seconds
- Manual dismiss: X button on each toast
- Animation: slide in from right (200ms ease-out), fade out (150ms)
- Width: 360px fixed

### Modal Behavior

- Overlay: `black/50` backdrop, click-to-close (unless form is dirty)
- Sizes: sm (400px), md (560px), lg (720px)
- Animation: fade in overlay (150ms) + scale up content from 95% (200ms ease-out)
- Close: X button top-right, Escape key, backdrop click
- Scroll: modal body scrolls independently, header/footer pinned
- Focus trap: tab cycles within modal while open

### Sidebar Behavior

- Desktop toggle: smooth width transition (200ms ease-in-out)
- Collapsed: icons only, tooltip on hover showing label (200ms delay)
- Mobile overlay: slides in from left (250ms), backdrop click to close
- State persistence: sidebar collapsed state stored in localStorage

### Breadcrumb Generation

- Strategy: route-based with manual label map
- Separator: `/` character in `gray-400`
- Segments derived from `$page.url.pathname` split by `/`
- Label map for known routes (e.g., `/clients` -> "Clients", `/tasks` -> "Tasks")
- Dynamic segments (UUIDs) replaced with entity display name when available
- Last segment: non-clickable, `gray-900` text
- Preceding segments: clickable, `gray-500` text, hover `blue-600`

### DataTable Behavior

- Sort: click column header to toggle asc/desc, indicator arrow in header
- Pagination: bottom of table, "Showing X-Y of Z" left, page buttons right
- Page sizes: 10, 25, 50 (dropdown selector)
- Loading: skeleton rows matching expected row count
- Empty: centered EmptyState component within table bounds
- Row hover: `gray-50` background
- Header: `gray-50` background, `gray-500` text, 12px font size, uppercase, 600 weight

### Form Validation

- Validation: on blur for individual fields, on submit for all fields
- Error display: red border on input, error message below (12px, `red-600`, 4px gap)
- Required indicator: asterisk (*) after label in `red-500`
- Disabled state: `gray-100` background, `gray-400` text, no cursor

### Button Variants

| Variant | Background | Text | Border | Hover |
|---------|-----------|------|--------|-------|
| primary | `blue-600` | `white` | none | `blue-700` |
| secondary | `white` | `gray-700` | `gray-300` | `gray-50` bg |
| ghost | transparent | `gray-600` | none | `gray-100` bg |
| danger | `red-600` | `white` | none | `red-700` |

All buttons: `rounded-md`, 44px height (md), 36px (sm), 48px (lg), 16px horizontal padding, focus ring 2px `blue-600` offset 2px.
