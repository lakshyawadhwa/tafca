<!-- API endpoints from 04-01 and 04-02 -->

Client API:
```
GET    /api/clients              -> { data: ClientResponse[], meta: { total, page, limit, totalPages } }
POST   /api/clients              -> ClientResponse (201)
GET    /api/clients/:id          -> ClientResponse (with gstNumbers, _count)
PATCH  /api/clients/:id          -> ClientResponse
DELETE /api/clients/:id          -> 204 (or 409 if active engagements)
POST   /api/clients/:id/gst-numbers       -> GstNumberResponse (201)
PATCH  /api/clients/:id/gst-numbers/:gstId -> GstNumberResponse
DELETE /api/clients/:id/gst-numbers/:gstId -> 204
```

Engagement API:
```
GET    /api/engagements          -> { data: EngagementResponse[], meta }
POST   /api/engagements          -> EngagementResponse (201)
GET    /api/engagements/:id      -> EngagementResponse
PATCH  /api/engagements/:id      -> EngagementResponse
PATCH  /api/engagements/:id/status -> EngagementResponse
```

EngagementType API:
```
GET    /api/engagement-types     -> EngagementType[] (all active, platform + firm)
GET    /api/engagement-types/:id/template -> TaskTemplateItem[] (for preview)
```
