# Phase 1: Database Schema & Prisma

## Goal
Define the complete PostgreSQL schema via Prisma, run the baseline migration, seed global data, and set up firm-scoped query enforcement.

---

## 1.1 Prisma Setup

### Enable multi-file schema
In `apps/api/package.json`:
```json
{
  "prisma": {
    "schema": "prisma/schema",
    "seed": "ts-node prisma/seed/index.ts"
  }
}
```

### Directory structure
```
apps/api/prisma/
├── schema/
│   ├── base.prisma           # datasource, generator, all enums
│   ├── auth.prisma           # User, Session, UserRoleHistory
│   ├── firm.prisma           # Firm
│   ├── client.prisma         # Client, ClientGstNumber, ClientCustomFieldDefinition
│   ├── engagement.prisma     # EngagementType, Engagement, EngagementCustomFieldDef
│   ├── task.prisma           # Task, TaskChecklist, TaskDependency, TaskComment, TaskActivityLog, TaskTemplate, TaskTemplateItem
│   ├── compliance.prisma     # StatutoryDeadline, StatutoryDeadlineOverride, ClientComplianceAssignment, ComplianceCalendarEntry
│   ├── document.prisma       # Document, DocumentRequest, DocChecklistTemplate, DocChecklistTemplateItem, DocChecklistInstance, DocChecklistInstanceItem
│   ├── credential.prisma     # CredentialLockerEntry, CredentialAccessLog
│   ├── dsc.prisma            # DscRecord
│   ├── team.prisma           # LeaveRecord
│   └── notification.prisma   # Notification
├── migrations/               # Auto-generated by prisma migrate
└── seed/
    ├── index.ts
    ├── statutory-deadlines.ts
    ├── engagement-types.ts
    └── task-templates.ts
```

### `updated_at` trigger function
```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ language 'plpgsql';

-- Apply to all tables with updated_at (example for firms, repeat for all)
CREATE TRIGGER set_updated_at BEFORE UPDATE ON firms
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
CREATE TRIGGER set_updated_at BEFORE UPDATE ON users
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
-- ... repeat for every table with updated_at
```

### Partial unique indexes (cannot be expressed in Prisma)
```sql
-- Only one primary GST per client
CREATE UNIQUE INDEX idx_gst_primary_per_client
  ON client_gst_numbers(client_id)
  WHERE is_primary = true AND deleted_at IS NULL;

-- Client display_name unique per firm (case-insensitive, excluding soft-deleted)
CREATE UNIQUE INDEX idx_clients_display_name_firm
  ON clients(firm_id, lower(display_name))
  WHERE deleted_at IS NULL;

-- Filtered index for active tasks
CREATE INDEX idx_tasks_assignee_active
  ON tasks(assignee_id, status)
  WHERE deleted_at IS NULL AND status NOT IN ('DONE', 'CANCELLED');

-- Filtered index for overdue detection
CREATE INDEX idx_tasks_due_date_active
  ON tasks(due_date)
  WHERE status NOT IN ('DONE', 'CANCELLED') AND deleted_at IS NULL;
```
